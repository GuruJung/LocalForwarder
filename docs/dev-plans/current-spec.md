# LocalForwarder 현재 기능 명세

이 문서는 새 개발 계획 체계에서 승인한 LocalForwarder v1의 현재 의도만 다룬다. 결정 배경과 수용 기준은 [기능 명세](specs/20261111-localforwarder-v1/spec.md)에 기록한다.

## 제품과 배포

- 시스템 OpenSSH를 실행하는 작은 네이티브 GUI이며 포워딩 프로토콜을 직접 구현하지 않는다.
- macOS 15 이상 Apple Silicon, Windows 11 x64·ARM64를 지원한다.
- GuruJung/LocalForwarder 공개 저장소에서 MIT 라이선스로 배포한다.
- GitHub 표준 네이티브 러너로 빌드하고 CPU별 ZIP을 제공한다. macOS는 ad-hoc 서명하며 유료 인증서 서명·공증은 포함하지 않는다.
- 설치 프로그램, 자동 업데이트, 로그인 시 자동 실행은 포함하지 않는다.

## 호스트와 규칙

- 매 실행마다 사용자가 호스트를 선택한다. 인스턴스 하나는 호스트 하나를 담당하며 아이콘도 별도로 가진다.
- SSH 별칭 또는 주소와 선택적 사용자명·포트·개인키 경로를 사용한다. 미지정 값은 기본 SSH 설정을 따른다.
- 앱의 활성 포워딩 규칙은 127.0.0.1에서만 접속을 받는다. 규칙별 활성화가 가능하다.
- 기존 SSH 포워딩은 읽기 전용으로 표시하고 그 설정대로 함께 실행한다.
- 명백한 입력 오류는 UI에서 확인하고, 실제 점유 포트나 호스트 중복은 미리 검사하지 않는다.
- 여러 포워딩 중 개설 실패가 하나라도 있으면 전체 연결을 실패 처리한다.

## 저장

- 실제 사용자 홈의 `.LocalForwarder/config.json`에 저장한다. 형식은 버전 1이며 호스트와 포워딩 목록으로 구성한다.
- 설정 열기와 모든 연결 작업 직전에 파일을 다시 읽고 저장을 즉시 수행한다. 장기 캐시와 변경 충돌 검사는 없다.
- 손상 파일을 보존하고 오류를 알린다. 동일 항목은 마지막 저장을 따른다.
- 연결 중 저장은 다음 연결 적용 또는 즉시 끊고 재연결을 선택한다. 다음 연결에는 자동 재연결도 포함된다.

## 연결 수명

- 일반 연결은 콘솔과 대화형 인증 입력 없이 수행한다. 각 연결 작업은 첫 실패 후 1초 뒤 한 번 재시도한다.
- 최초 성공 후 창을 숨기고 connected 아이콘을 표시한다. 최초 최종 실패는 원인 확인 후 종료한다.
- 비의도적 단절을 감지하면 disconnected로 전환하고 60초 후 자동 재연결한다. 재연결 최종 실패 후 60초가 지나면 종료한다.
- 자동 재연결은 단절 주기마다 한 차례이며, 실패 후 자동 반복하지 않는다. 성공한 뒤 다시 단절되면 새 주기가 시작된다.
- 대기 중 수동 재연결은 기존 예약을 대체한다. 성공하면 예약을 취소하고 실패하면 다시 60초 뒤 종료한다.
- 재연결 중 중복 요청을 막으며 사용자 종료와 설정 적용을 위한 의도적 종료는 자동 재연결을 발생시키지 않는다.
- 절전 중 경과 시간도 대기에 포함한다. 복귀 시 지난 자동 재연결 기한에는 한 차례 재연결하고, 지난 종료 기한에는 종료한다.
- 연결 상태는 SSH 및 포워딩 개설 상태를 뜻한다. 목적지 서비스 장애는 검사하지 않는다.

## UI와 인증 복구

- 연결 중 트레이 메뉴는 설정·종료, 단절 대기 중에는 재연결을 추가한다. 호스트와 상태를 툴팁으로 구별한다.
- 자동 재연결 실패는 창이나 터미널을 자동으로 띄우지 않고 설정 화면에 원인을 남긴다.
- 종료 선택은 예약을 취소하고 해당 인스턴스의 SSH만 정리한 뒤 즉시 종료한다.
- 인증·최초 호스트 신뢰 문제는 안내 후 외부 터미널에서 해결하며 GUI는 종료한다. 단절 후에는 설정 화면에서 사용자가 복구를 선택한다.
- 사용 가능한 기존 키를 우선 사용하고 필요한 새 키는 암호 없이 생성한다. 비밀번호와 개인키 암호는 터미널에서만 입력한다.
- 일반 Linux/macOS 계정의 공개키 등록을 지원하며 기존 키를 보존하고 중복 등록하지 않는다. 서버 인증 정책과 변경된 호스트 키를 자동 우회하지 않는다.
- 유휴 상태는 이벤트와 일회성 타이머로 대기한다. 배포 크기와 실제 유휴 CPU·메모리를 보고하고 임의 수치 목표를 도입하지 않는다.
