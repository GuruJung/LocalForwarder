# Tracked Feature Spec

## 목표와 동작

macOS와 Windows의 포워딩 규칙에 선택적 `description`을 추가한다. 설명은 설정창 목록과 규칙 편집 팝업에서만 표시한다.

- `새 규칙…`·`규칙 편집…` 팝업의 사용 여부 아래에 **설명 (선택)** 한 줄 입력란을 추가한다. 신규 규칙의 설명은 빈 값이다.
- 설정창 포워딩 목록의 마지막 열에 **설명**을 표시한다. 설명 편집은 기존 편집 버튼과 더블클릭으로 수행한다.
- 확인하면 설명을 포함한 규칙을 초안에 반영한다. 취소·Escape·닫기는 변경을 버린다. 기존 규칙의 ID·순서와 선택 호스트 저장 정책을 유지한다.
- 설명은 사람이 용도를 기록하는 정보다. SSH 명령, 포워딩 상태 판정, 연결·재시도에는 사용하지 않는다.
- 설명 변경은 미저장 변경으로 표시하되, 설명만 다르다는 이유로 실행 연결 설정이 다르다는 경고를 표시하지 않는다.
- 트레이와 연결 상태 팝업의 표시, SSH 설정에서 상속한 규칙은 변경하지 않는다.

## 저장과 호환성

- 규칙 JSON에 선택 문자열 `description`을 추가하고 설정 버전 **2**를 유지한다.
- 누락·`null`·빈 문자열은 설명 없음으로 읽으며, 빈 설명은 저장 시 해당 필드를 생략한다.
- 기존 호스트 설명과 동일하게 개행과 NUL을 거부한다. 문자열이 아닌 값은 설정 오류로 처리한다.
- 기존 v1/v2 설정을 계속 읽고, 읽기만으로 파일을 수정하지 않는다. v1 최초 저장의 원본 백업 정책을 유지한다.
- 선택 저장·재읽기·다른 호스트 저장·인증 키 갱신에서 규칙 설명을 보존한다.
- 구버전 앱에서 다시 저장하면 새 설명 필드가 유실될 수 있다는 제한을 문서화한다.

## 사용자 결정

| 주제 | 선택 | 이유·범위 |
|---|---|---|
| 규칙 설명 | `description` 추가, 누락 허용 | 이전 설정과의 호환성을 요청 |
| 표시 위치 | 설정창 목록과 편집 팝업 | 추천안 선택, 별도 이유 미제시 |

플랫폼은 기존 개발 범위에 따라 macOS·Windows 모두 적용한다. 한 줄 입력과 빈 값 처리 방식은 기존 호스트 설명의 규칙을 따른다.

## Current Spec Impact

현재 명세 전체의 한국어와 기존 의도를 유지한다.

- **add:** 포워딩 규칙 설명의 용도·선택적 저장·기존 설정 호환성.
- **replace:** 규칙 모달의 입력 항목에 설명을, 설정창 목록에 설명 열을 추가.
- **add:** 설명은 미저장 판단에 포함하지만 실행 연결 설정 비교에서는 제외.
- 기존 연결 정책·모달 확인/취소·선택 저장·호스트 설명·트레이 표시 정책은 유지.

## 수용 기준

- 설명이 없는 기존 설정으로 기존과 동일하게 실행·편집·저장할 수 있다.
- 한글 설명을 양쪽 플랫폼에서 저장하고 다시 읽어도 보존한다.
- 추가·편집·취소·설명 삭제가 정확히 반영되며 다른 규칙이나 호스트를 변경하지 않는다.
- 설명만 변경해도 SSH 명령과 현재 연결은 유지되고 불필요한 실행 설정 차이 경고가 생기지 않는다.
- 작은 설정창에서도 포트 정보와 설명에 접근할 수 있고 모달 입력·버튼이 겹치지 않는다.
