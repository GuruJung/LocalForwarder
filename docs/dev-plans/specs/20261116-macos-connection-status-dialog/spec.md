# Tracked Feature Spec

### 변경 내용

macOS 설정 창의 현재 연결 상태 영역을 별도 모달 팝업으로 옮긴다.

- `인증 설정…` 바로 오른쪽에 `연결 상태…` 버튼을 배치한다.
- 선택한 호스트의 이름과 SSH 대상, 연결 요약, 임시 실행 설정 안내, 최근 오류, 포워드별 상태·출처·상세, ‘준비됨’의 의미를 팝업에 표시한다.
- 팝업이 열린 동안 설정 편집을 막고, 연결 상태는 계속 실시간 갱신한다. 표시 대상은 팝업을 열 때 선택한 호스트로 고정한다.
- `닫기` 버튼과 Escape로 팝업만 닫는다. 설정 창과 미저장 편집은 그대로 유지한다.
- 연결 이력이 없는 신규 호스트에서도 열 수 있으며, 연결 안 됨과 빈 상태 표를 표시한다.
- **편집한 값의 SSH 명령 프리뷰는 설정 창에 유지**한다. 상태 내용은 설정 창에 중복 표시하지 않는다.
- 팝업 열기·닫기는 저장·연결·재연결·자동 복구를 유발하지 않는다. 상태 정보는 실제 실행 상태를 기준으로 하며 미저장 편집값을 실행 결과처럼 표시하지 않는다.

이 기능의 초기 구현 범위에서는 Windows, 설정 파일 형식, CLI, 연결·복구 정책을 변경하지 않았다. 이는 기능 범위 기록이며 Windows 수정 제한이 아니다. 현재 제품 의도와 구현 차이는 [현재 명세](../../current-spec.md)를 따른다. 팝업에 연결 조작 기능이나 서비스 상태 검사 기능을 추가하지 않는다.

### 사용자 결정

| 주제 | 선택 | 이유·적용 범위 |
|---|---|---|
| 접근 위치 | 인증 설정 버튼 옆에 새 버튼 | 별도 이유 미제시 |
| 창 동작 | 닫은 뒤 설정을 편집하는 모달 방식 | 별도 이유 미제시 |
| 이동 범위 | 현재 연결 상태만 이동 | 명령 프리뷰는 설정 창에 유지하는 선택 |

### Current Spec Impact

- **replace:** macOS의 현재 연결 상태 표시 위치를 설정 폼 내부에서 `연결 상태…`로 여는 모달 팝업으로 변경한다.
- **add:** 버튼 위치, 선택 호스트 고정, 실시간 갱신, 닫기와 편집 보존 동작을 명시한다.
- 기존 상태의 의미·오류 정보·실행 설정 구분을 유지하고, 현재 명세 전체의 한국어를 유지한다.
- macOS 전용 UI 변경이므로 Windows 반영 대기 항목을 추가하지 않는다.

### 수용 기준

1. 인증 설정 옆 버튼으로 상태 팝업이 열리고, 기존 상태 정보가 빠짐없이 표시된다.
2. 팝업을 닫기 전에는 설정을 편집할 수 없으며, 닫은 뒤 기존 편집을 이어갈 수 있다.
3. 팝업을 열어 둔 상태에서 SSH 종료와 포워드 상태 변경이 반영된다.
4. 호스트를 바꿔 다시 열면 해당 호스트의 상태만 보인다. 신규·미연결 호스트에 이전 호스트 정보가 남지 않는다.
5. 기본·최소 창 크기에서 버튼이 겹치지 않고, 긴 오류와 많은 포워드도 스크롤하여 확인할 수 있다.
6. 열기·닫기·중복 실행의 설정 열기 요청으로 저장값이나 연결 의도가 바뀌거나 팝업이 중복 생성되지 않는다.
