# Tracked Feature Spec

### 변경 내용

- 트레이의 **호스트 메뉴 행 툴팁만 제거**한다. 서브메뉴의 연결 상태·오류 표시와 트레이 아이콘의 연결 개수 툴팁은 유지한다.
- 왼쪽 패널 상단에 `새로 만들기`와 `호스트 삭제…`를 같은 행으로 배치하고, 아래에 호스트 목록을 둔다.
- 오른쪽 설정에서 `사용자명`과 `SSH 포트`를 같은 행에 배치한다. 사용자명 입력은 남는 폭을 사용하고 포트 입력은 짧게 둔다.
- `개인키` 입력과 `개인키 파일 선택…` 버튼을 같은 행에 배치한다.
- `Cancel`과 `OK`는 좌우 패널 바깥의 **창 하단 고정 영역에 오른쪽 정렬**한다. 오른쪽 내용을 스크롤해도 항상 보이게 한다.
- 선택 호스트 저장·연결·인증 버튼은 오른쪽 호스트 설정 영역에 유지한다.
- 폼이 오른쪽 가용 너비를 채우도록 유지하고, 지원하는 최소 창 크기에서도 버튼과 입력 항목이 겹치거나 잘리지 않게 한다.

연결·복구·저장·삭제·미저장 경고의 의미, Enter/Escape 키 동작, 설정 파일 형식과 CLI는 변경하지 않는다. 이 기능의 초기 구현 범위에서는 Windows 구현을 변경하지 않았다. 이는 기능 범위 기록이며 Windows 수정 제한이 아니다. 현재 제품 의도와 구현 차이는 [현재 명세](../../current-spec.md)를 따른다.

### 사용자 결정

| 주제 | 선택 | 이유·적용 범위 |
|---|---|---|
| 호스트 툴팁 | 제거 | 서브메뉴의 상태 표시와 중복됨 |
| 호스트 관리 버튼 | 상단 한 행으로 묶기 | 별도 이유 미제시 |
| 입력 배치 | 사용자명·포트, 개인키·선택 버튼을 각각 한 행으로 묶기 | 별도 이유 미제시 |
| Cancel·OK | 양쪽 패널보다 아래의 공통 영역으로 이동 | 창 전체에 속하는 레이아웃으로 구분 |
| 반영 대상 | 기존 폼 너비 수정과 이번 변경을 a05 로컬 main에 통합하고 Mac 재설치 | 사용자가 방향을 확인하고 승인함 |

하단 버튼의 오른쪽 정렬과 고정 표시는 이번 계획의 기본 배치로 채택한다.

### Current Spec Impact

- **replace:** 「편집과 저장」의 좌우 패널 설명을 상단 호스트 관리 행, 묶인 입력 행, 공통 하단 버튼 영역으로 구체화한다.
- **add:** macOS 호스트 메뉴 행에는 툴팁을 표시하지 않으며 상태는 서브메뉴에서 확인한다는 의도를 추가한다.
- **clarify:** 기존 연결 개수 툴팁은 트레이 **아이콘**에 대한 요구임을 명확히 한다.
- 현재 명세 전체의 한국어와 기존 동작 의도를 유지한다. macOS 전용 UI 변경이므로 Windows 이식 대기 기능으로 추가하지 않는다.

### 수용 기준

1. 호스트 메뉴에 마우스를 머물러도 툴팁이 나오지 않고 서브메뉴 상태는 정상 표시된다.
2. 요청한 세 묶음이 각각 같은 행에 표시된다.
3. 폼 스크롤 위치와 관계없이 Cancel·OK가 창 하단에 보인다.
4. 기본 크기와 최소 크기에서 입력·버튼이 겹치지 않으며 오른쪽 폼이 가용 폭을 채운다.
5. 이동한 버튼의 동작과 미저장 경고가 유지되고, 설정창 조작만으로 기존 연결이나 저장 설정이 바뀌지 않는다.
