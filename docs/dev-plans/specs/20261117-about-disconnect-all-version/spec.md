# Tracked Feature Spec

## 요약 및 요구사항

macOS·Windows에 About 모달과 전체 연결 끊기를 추가하고, 공통 제품 버전 `0.1.0`을 앱 정보와 태그 기반 배포에 사용한다.

### About

- 트레이 메뉴의 `종료` 바로 위에 `About...`을 추가한다.
- 선택하면 기존 프로그램 아이콘, `LocalForwarder`, 제품 버전, 개발자 `GuruJung`, `https://github.com/GuruJung/LocalForwarder`를 보여주는 네이티브 모달을 연다.
- GitHub URL은 클릭하면 기본 브라우저로 연다. 모달을 여는 것만으로 네트워크 요청을 하지 않는다.
- 닫기 버튼·Escape·창 닫기로 종료한다. 중복 실행은 기존 모달을 앞으로 가져온다.
- 모달은 앱의 다른 사용자 조작을 차단하되 SSH 연결과 상태 갱신은 계속한다. 설정 초안·연결 의도·설정 파일을 변경하지 않는다.

### 전체 연결 끊기

- 기존 `전체 재연결`의 명칭과 동작을 유지하고, 바로 아래에 `전체 연결 끊기`를 추가한다.
- 확인 문구는 “모든 호스트의 연결을 끊으시겠습니까?”로 하고, 연결 중 작업과 자동 복구 대기도 취소됨을 설명한다. `취소`를 기본 선택으로 하고 `연결 끊기`를 명시적으로 선택해야 실행한다.
- 취소·Escape·창 닫기는 아무 연결 작업도 실행하지 않는다.
- 확인 시점의 모든 관리 호스트를 대상으로 한다. 자동 연결 OFF인 수동 연결, 미저장 임시 호스트, 연결 중·재시도 대기·복구 대기도 포함한다.
- 모든 연결 의도를 OFF로 바꾸고 예약과 연결 작업을 취소하며, 앱이 관리하는 해당 SSH 프로세스를 정리한다. 뒤늦은 콜백이나 절전·네트워크 복구 이벤트가 연결을 되살리지 않아야 한다.
- 저장된 자동 연결 옵션, 설정 초안, 임시 실행 설정, 호스트 목록은 보존한다. 이후 개별 연결·전체 재연결·앱 재시작은 기존 정책을 따른다.
- 앱과 트레이는 계속 실행한다. 설정 파일이 손상되어도 현재 연결은 끊을 수 있어야 한다.
- 연결·작업·연결 의도가 모두 없는 경우 메뉴를 비활성화한다. 연결 중에도 사용할 수 있고, 확인창과 전체 끊기의 중복 실행은 방지한다.

### 버전과 배포

- macOS·Windows는 하나의 제품 버전을 사용한다. 초기값은 `0.1.0`이며 이후 `major.minor.patch` 형태로 명시적으로 갱신한다.
- About, macOS 번들 정보, Windows 실행 파일 버전 정보, ZIP 이름이 같은 제품 버전을 나타내야 한다. 설정 형식 `"version": 2`와는 독립적이다.
- ZIP 이름은 `LocalForwarder-<version>-<platform>-<arch>.zip`으로 한다. 기존 macOS arm64, Windows x64·arm64 세 배포 대상을 유지한다.
- `v<version>` 태그 push를 배포 계기로 삼는다. 태그와 소스 버전이 일치하고 세 대상의 검증·패키징이 모두 성공한 경우에만 ZIP 세 개를 GitHub Release에 공개한다.
- 일반 브랜치·PR 검증은 Release를 발행하지 않는다. 빌드마다 자동 버전 증가, 자동 태그 생성, 앱 자동 업데이트, 설치 프로그램, 유료 서명·공증은 추가하지 않는다.
- 이번 작업은 배포 자동화 구축까지이며, 첫 배포용 태그 생성·push와 실제 Release 발행은 포함하지 않는다.

## 사용자 결정

| 주제 | 선택 | 이유·범위 |
|---|---|---|
| 플랫폼과 메뉴 | 양쪽 플랫폼 적용, `전체 재연결` 명칭 유지 | 제시된 메뉴 배치 선택. 별도 이유는 제시하지 않음 |
| 배포 방식 | 공통 버전 및 태그 기반 GitHub Release | 두 플랫폼이 같은 제품 버전을 사용함을 설명한 뒤 선택. 별도 이유는 제시하지 않음 |
| 초기 버전 | `0.1.0` 유지 | 현재 macOS 버전을 공통 시작값으로 선택. 별도 이유는 제시하지 않음 |
| About 정보 | 아이콘·이름·버전·GuruJung·GitHub URL | 사용자가 직접 요청한 표시 항목 |
| 전체 끊기 | 한 번 확인 후 모든 호스트 수동 단절 | 사용자가 직접 요청한 동작 |

위에 명시한 취소 기본 선택, 임시 설정 보존, 버전 파일·배포 파일명 규칙은 구현 기본값이다.

## Current Spec Impact

`docs/dev-plans/current-spec.md`에 다음 의도를 반영한다. 전체 문서의 한국어와 기존 의미·검증 공백을 유지한다.

- **add:** About 모달의 표시 항목·수명·부작용 없음.
- **add:** 전체 연결 끊기의 대상, 확인, 의도 OFF, 예약 취소, 설정 보존.
- **add:** 공통 제품 버전, OS 메타데이터, 버전 포함 ZIP, 태그 기반 Release 조건.
- **replace:** 트레이 순서를 `설정 / 로그인 자동 시작 / 전체 재연결 / 전체 연결 끊기 / 구분선 / 호스트별 메뉴 / 구분선 / About... / 종료`로 갱신한다.
- 기존 개별 끊기·전체 재연결·자동 복구·설정 v2 계약은 유지한다.

## 수용 기준

- 양쪽 About이 동일한 제품 정보를 표시하고 정상적으로 모달 동작하며 기존 연결·초안을 보존한다.
- 전체 끊기를 취소하면 상태가 변하지 않는다. 확정하면 모든 대상이 최종 미연결·의도 OFF가 되고 이전 예약으로 재접속하지 않는다.
- 전체 끊기 이후 수동 연결과 전체 재연결은 정상 동작한다.
- 저장 설정과 임시 실행 설정은 전체 끊기로 유실되지 않는다.
- About·OS 정보·ZIP 이름·태그가 같은 버전을 가리킨다.
- 잘못된 태그, 버전 불일치, 검증 실패, 배포물 누락 시 공개 Release가 생성되지 않는다.
