# Tracked Feature Spec

## 목표와 동작

영어 README의 한국어 UI 명칭 병기를 정리하고, macOS·Windows 설정창에 포워딩 규칙을 로컬 포트순으로 정렬하는 버튼을 추가한다.

**문서**

- `README.md`의 메뉴·버튼·상태 설명을 실제 영어 UI 명칭으로 맞춘다. 괄호 속 한국어와 로그인 등록 상태의 한국어 표기를 영어로 교체한다.
- 한국어 README로 이동하는 `한국어` 링크는 유지한다.
- 정렬 기능의 사용법과 명시적 저장 필요성을 영어·한국어 README에 각각 안내한다.

**정렬**

- 포워딩 목록의 기존 규칙 작업 버튼 뒤에 **Sort by Local Port / 로컬 포트순 정렬** 버튼을 추가하고 지원하는 7개 언어로 제공한다.
- 클릭 시 선택 호스트의 앱 정의 규칙 전체를 **로컬 포트 숫자 오름차순**으로 정렬한다. 비활성 규칙도 포함하며 같은 포트끼리는 기존 상대 순서를 유지한다.
- 정렬은 초안의 순서를 변경한다. 실제 순서가 바뀌면 기존 미저장 판단을 적용하고, 사용자가 저장하면 다시 열거나 재시작해도 유지한다. 저장하지 않고 닫으면 기존 편집 취소 정책을 따른다.
- 이미 정렬된 목록은 그대로 유지한다. 호스트 미선택 또는 규칙이 2개 미만이면 버튼을 비활성화한다.
- 선택한 규칙은 ID를 기준으로 유지한다. 규칙의 ID·포트·목적지·설명·활성 상태, 다른 호스트의 초안, 입력 중인 호스트 정보는 보존한다.
- 버튼 클릭만으로 저장·연결·재연결하지 않는다. 현재 실행의 연결·포워딩 상태·예약을 유지하고 명령 프리뷰만 초안 순서에 맞춰 갱신한다.
- 기존 모달 조작 차단을 따른다. 이름·SSH 대상 등 호스트 입력이 미완성이어도 정렬할 수 있다.
- 자동 정렬, 내림차순, 목적지 포트 정렬, 열 제목 클릭 정렬, 상속 규칙·연결 상태 표의 별도 정렬은 포함하지 않는다. 규칙 추가·편집 후에는 기존 배치 방식을 유지하고 버튼을 다시 눌렀을 때 정렬한다.

## 사용자 결정

| 주제 | 선택 | 이유·범위 |
|---|---|---|
| README 표기 | 한국어 UI 명칭 병기 제거 | 프로그램이 영어를 포함한 여러 언어를 지원하므로 불필요하다고 판단 |
| 정렬 기준 | 로컬 포트 오름차순 | 추천안 선택, 별도 이유 미제시 |
| 정렬 저장 | 초안 변경 후 명시적 저장 | 추천안 선택, 별도 이유 미제시 |

같은 포트의 순서 유지, 비활성 규칙 포함, 버튼 위치·비활성 조건, 한국어 README 링크 유지는 구현 기본안으로 정한다.

## Current Spec Impact와 수용 기준

**Current Spec Impact: add.**

- 현재 명세의 문서 정책에 영어 README가 영어 UI 명칭을 사용하고 한국어 병기를 하지 않는다는 내용을 추가한다.
- 편집·저장 정책에 명시적 로컬 포트 정렬, 초안·저장 동작, 선택 규칙 보존을 추가한다.
- 문서 전체의 한국어와 기존 제품 의도·검증 공백을 유지한다. 설정 v2, 선택 호스트 저장, 실행 설정 비교, 트레이의 실행 스냅샷 정책은 유지한다.

양쪽 플랫폼에서 숫자 정렬·동률 순서·선택 보존·저장과 취소가 일치해야 한다. 정렬 후에도 편집·삭제·체크박스가 올바른 규칙에 적용되어야 하며, 작은 창과 지원 언어·Windows DPI 검사에서 새 버튼에 접근할 수 있어야 한다.
