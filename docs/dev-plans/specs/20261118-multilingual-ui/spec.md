# Tracked Feature Spec

## 요약과 지원 범위

macOS·Windows에서 영어, 한국어, 중국어 간체·번체, 일본어, 스페인어, 독일어를 내장 지원한다. 최초 실행과 언어 선택 기록이 없는 기존 사용자는 시스템 선호 언어를 따르고, 지원 언어가 없으면 영어를 사용한다.

트레이·설정창·규칙 편집·연결 상태·About·검증 및 오류 안내·앱이 작성한 터미널 인증 안내를 번역한다. 사용자 입력, SSH 명령과 옵션, 파일 경로, 제품명, 외부 프로그램·운영체제의 원문 진단은 유지한다. OS 파일 선택창 등 시스템 제공 UI의 기본 문구는 OS 언어를 따른다.

외부 언어 파일 검색·로딩, 번역 다운로드, 실행 중 OS 언어 변경 감지, 추가 언어의 README 작성은 포함하지 않는다.

## 언어 메뉴와 전환

트레이 메뉴의 **설정 바로 아래**에 언어 서브메뉴를 추가한다. 나머지 메뉴의 상대적 순서는 유지한다.

서브메뉴는 다음 순서로 표시한다. 언어 이름은 현재 UI 언어와 관계없이 아래 표기를 유지한다.

1. `Automatic (System Language — <적용 언어>)`에 해당하는 현재 언어의 번역
2. 가로 구분선
3. `Chinese (Simplified) — 简体中文`
4. `Chinese (Traditional) — 繁體中文`
5. `English`
6. `German — Deutsch`
7. `Japanese — 日本語`
8. `Korean — 한국어`
9. `Spanish — Español`

- 영어 이름의 알파벳순을 고정한다. 자동 모드에서는 자동 항목에만, 수동 모드에서는 선택 언어에만 체크한다.
- 선택은 사용자별로 저장하며 앱 재시작 후 유지한다. 호스트 설정과 별개로 관리한다.
- 선택 즉시 트레이·툴팁·열린 설정창·앱이 생성한 상태 및 오류 설명을 갱신한다.
- 미저장 입력, 선택 호스트, 편집 포커스, 스크롤 위치, SSH 연결, 연결 의도, 재시도·복구 예약을 보존한다. 언어 변경으로 저장·재연결·인증을 실행하지 않는다.
- 모달이 열린 동안은 기존 조작 차단 정책에 따라 언어 변경을 허용하지 않는다. 이후 여는 대화상자는 변경된 언어를 사용한다.
- 인증 도우미는 실행 요청 당시의 적용 언어를 사용한다. 이미 실행 중인 도우미의 언어는 유지한다.

## 자동 선택과 실패 처리

- OS의 사용자 선호 UI 언어 목록을 순서대로 검사해 첫 번째 지원 언어를 선택한다. 지역 변형은 해당 지원 언어로 대응하며, 일치하는 언어가 없으면 영어를 사용한다.
- 중국어는 명시적 문자 체계를 우선한다. `Hans`는 간체, `Hant`는 번체이며, 문자 체계가 없으면 중국·싱가포르는 간체, 대만·홍콩·마카오는 번체로 대응한다. 지역 없는 `zh`는 간체로 처리한다.
- 간체 번역은 중국 본토 용어, 번체 번역은 대만 용어를 기준으로 한다. 홍콩 전용 번역은 제공하지 않는다.
- 자동 선택은 앱 시작과 사용자가 자동 항목을 선택할 때 평가한다.
- 없거나 알 수 없는 저장 언어 값은 자동으로 해석한다. 특정 번역 문구를 사용할 수 없으면 해당 문구의 영어 번역으로 대체한다.
- 언어 설정 저장 실패가 확인되면 기존 선택과 화면 언어를 유지하고 오류를 안내한다. 호스트 설정과 실행 중인 연결에는 영향을 주지 않는다.

## 사용자 결정

| 주제 | 선택 | 이유·적용 범위 |
|---|---|---|
| 확장 방식 | 우선 내장 언어 지원 | 사용자 별도 이유 없음. 외부 언어 파일은 이번 범위에서 제외 |
| 기본 동작 | 시스템 언어 자동 선택, 영어 대체 | 사용자 별도 이유 없음. 신규·선택 기록 없는 기존 사용자에 적용 |
| 언어 구성 | 간체·번체 모두 및 일본어 포함, 총 7개 | 사용자 별도 이유 없음 |
| 변경 시점 | 즉시 적용 | 연결과 미저장 입력을 유지하는 안 선택 |
| 번역 범위 | 터미널 인증 안내까지 포함 | 실행 중인 도우미는 시작 당시 언어 유지 |
| 메뉴 표현 | 영어명과 자국어명, 자동에 단일 체크 | 영어명 알파벳순 및 적용 언어 표시안 선택 |

메뉴 위치, 중국어 지역 대응, 시스템 제공 문구의 예외는 구현 기본안으로 정한다.

## 수용 기준과 Current Spec Impact

- 양쪽 플랫폼에서 7개 언어와 자동 선택의 순서·체크·재시작 유지가 일치한다.
- 지원·미지원 시스템 언어, 중국어 문자 체계 및 지역 변형을 명세대로 처리한다.
- 연결 중 또는 편집 중 언어를 변경해도 입력·실행 상태를 유지하며, 기존에 발생한 앱 자체 오류도 새 언어로 표시한다.
- 앱이 작성한 사용자 대상 문구에 번역 누락이 없고, 치환값과 원문 진단이 손상되지 않는다.
- 긴 번역과 CJK 문자를 정상 표시하며, 기본·좁은 창 및 Windows DPI 검사에서 조작 요소가 겹치거나 접근 불가능하게 잘리지 않는다.
- 기존 설정 v2, SSH 동작·진단 판정, 모달 정책, 플랫폼별 버튼 순서를 유지한다.

**Current Spec Impact: add + replace.** 현재 명세에 다국어·자동 선택·즉시 전환·번역 범위·실패 처리 정책을 추가하고, 트레이 메뉴 순서를 언어 메뉴가 포함된 순서로 교체한다. 기존 한국어 UI 문구 예시는 고정 표시 요구가 아닌 한국어 번역 예시임을 명시한다. 문서 전체의 한국어와 나머지 제품 의도·검증 공백은 유지한다.
